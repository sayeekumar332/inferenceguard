# InferenceGuard — Real-GPU-Validated Inference Verification

## Overview

InferenceGuard verifies inference repeatability, detects token-level output differences, and observes vLLM prefix-cache behavior.

The project has been validated on a real **NVIDIA Tesla T4 GPU** using **vLLM 0.33.0** and **Qwen/Qwen3-0.6B**. In one controlled experiment, it recorded:

- Three completed inference requests, with identical generated token IDs across all three
- Zero token mismatches
- 1,689 prefix-cache query tokens
- 1,120 prefix-cache hit tokens
- 66.31% aggregate token-level cache-hit ratio

These results provide real-hardware evidence for the integrated verification workflow. For the environment, measurements and methodology, see the [NVIDIA Tesla T4 Experiment Report](../../experiments/vllm_cache_observability_t4/T4_EXPERIMENT_REPORT.md).

## Customer demonstration suite

The three demonstrations below complement the real-GPU experiment. They send real HTTP requests to a **local simulated OpenAI-compatible inference endpoint** and use InferenceGuard's existing verification engine. The completion responses and token IDs in these three demonstrations are simulated, **not generated by an LLM**. No GPU or vLLM installation is needed to run them locally.

## Requirements

- Python 3.12 and a working InferenceGuard installation
- No NVIDIA GPU or vLLM installation required for the three local demonstrations

From the repository root, install the project if needed:

```bash
python -m pip install -e .
```

## Demo 1 — Healthy inference

```bash
python -m demos.customer_demo.healthy_demo \
  --output /tmp/inferenceguard_healthy_demo.json
```

Expected: three completed requests, identical simulated token-ID sequences, zero mismatches, inference verdict `PASS`, and exit code `0`.

## Demo 2 — Token-level regression detection

```bash
python -m demos.customer_demo.regression_demo \
  --output /tmp/inferenceguard_regression_demo.json
```

Expected: three completed HTTP requests; one deliberately changed token ID in the second response; unchanged response text; inference verdict `FAIL`; mismatch indices `[1]`; exit code `1`.

The nonzero exit code intentionally indicates detection of the injected regression, not a failure to execute the demo.

## Demo 3 — Prefix-cache metrics unavailable

```bash
python -m demos.customer_demo.metrics_unavailable_demo \
  --output /tmp/inferenceguard_metrics_unavailable.json
```

Expected: three completed inference requests with identical simulated token IDs; inference verdict `PASS`; cache observability status `UNAVAILABLE`; cache deltas `[null, null, null]`; explicit error details; exit code `0` under the current CLI policy.

**An inference `PASS` does not mean that prefix-cache observability succeeded.** Consumers requiring cache measurements must also inspect `cache_observability.status`.

## Verification

Run the customer demonstration tests:

```bash
python -m pytest \
  tests/test_customer_demo_healthy.py \
  tests/test_customer_demo_regression.py \
  tests/test_customer_demo_metrics_unavailable.py \
  -v
```

Run the complete repository checks:

```bash
python -m ruff check .
python -m ruff format --check .
python -m pytest -q
git diff --check
```

At the completion of the three demonstration scenarios, the full regression suite contained **170 passing tests**.

## Scope and next validation opportunities

The local demonstrations use intentionally simulated token IDs to make successful, failing, and unavailable-metrics outcomes reproducible on a normal computer. The separately archived Tesla T4 experiment supplies **real model-inference evidence**.

Additional GPUs, models, serving configurations and deployment workloads are natural next validation targets. The observed cache-hit ratio measures token reuse, rather than latency or financial savings; the original [vLLM issue #40896](https://github.com/vllm-project/vllm/issues/40896) remains a motivating scenario, not a reproduced or resolved upstream defect.

## Conclusion

InferenceGuard combines real NVIDIA Tesla T4 inference verification evidence with reproducible local demonstrations of healthy inference, injected token-level regression detection, and unavailable cache observability.
